# MuZero

状态：教程与研究路线规划，尚未实现。

目标是在 AlphaZero 基础上研究：当搜索无法直接使用真实环境的状态转移时，如何学习支持规划的模型。

## 拟定学习顺序

1. 表征网络：将观测或观测历史编码为隐状态。
2. 动力学网络：根据隐状态和动作预测下一隐状态与奖励。
3. 预测网络：根据隐状态预测策略和价值。
4. 隐状态 MCTS：使用学习模型展开搜索，明确奖励、折扣和玩家视角。
5. 序列回放与训练：展开多步模型，构造奖励、策略和价值目标，处理终局与样本边界。
6. 对照实验：在相同游戏和明确的计算预算下，与使用真实规则搜索的基础路线比较。

真实环境仍负责交互与评估；搜索内部使用学习模型，不通过真实环境的后继状态替代动力学预测。根节点合法动作与内部搜索动作的处理方式须单独说明。

先建立可验证的基础流程，再安排扩展研究。研究假设、已实现方法和经过实验支持的结论分开记录。

参考：[MuZero 论文及官方伪代码入口](https://arxiv.org/abs/1911.08265)。
